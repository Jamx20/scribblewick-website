# scribblewick-website

## Free printables gallery

The gallery is `free/index.html`. To add a pack, copy the Fairy Forest `<article class="pack">` in that file. Put the pack in `free/<folder>/` with its page, PDFs, `preview.webp`, and a `thumb.webp` about 600px wide (a same-aspect crop of the preview, not stretched). Point the card image at `<folder>/thumb.webp` and the button at `<folder>/`.
